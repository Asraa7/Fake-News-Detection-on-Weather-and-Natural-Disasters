# 🌪️ Fake News Detection — Weather & Natural Disasters

A Machine Learning web application that classifies news headlines/articles about weather and natural disasters as **Real** or **Fake**.

## 🔧 Tech Stack
- **Language:** Python
- **ML:** Scikit-learn (Logistic Regression, Naive Bayes)
- **NLP:** TF-IDF Vectorisation
- **Web App:** Flask
- **Libraries:** Pandas, NumPy

## 🚀 How to Run

1. Install dependencies:
```
pip install -r requirements.txt
```

2. Train the model:
```
python train.py
```

3. Launch the web app:
```
python app.py
```

4. Open your browser and go to:
```
http://127.0.0.1:5000
```
